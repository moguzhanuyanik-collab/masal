# İlkAdım V1.0.45 — Kullanıcı Ekleme Formlarında Otomatik Doldurma Düzeltmesi

- Global Öğrenci ekleme formunda e-posta otomatik doldurma kapatıldı.
- Global Veli ekleme formunda e-posta otomatik doldurma kapatıldı.
- Kurum Yöneticisi / Öğretmen / Veli / Öğrenci ekleme formlarında e-posta otomatik doldurma kapatıldı.
- Gelişmiş Yetkilendirme ekranındaki yeni kullanıcı formunda otomatik doldurma kapatıldı.
- Yeni hesap e-posta alanları ayrı form alan adı kullanır.
- Yeni hesap şifre alanları `autocomplete="new-password"` olarak işaretlendi.
- Giriş ekranındaki e-posta/şifre hatırlama davranışı değiştirilmedi.
- Mevcut kullanıcılar, kurumlar, veritabanı kayıtları, CSS ve görseller değiştirilmedi.
